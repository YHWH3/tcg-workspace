| P4-C18 | Authenticated completion read chunk aggregates and workspace usage before an unconditional independent UPDATE. SVG replacement and completion share one guarded D1 batch; injected final-update failure returns `503` and preserves the original pending bytes. Existing seven chunk/upload regressions remain passing. |
| P4-C19 | Public-form recovery compared the live form row to the reservation but planned against the reserved board schema.
